# CASE001
A mystery website with many unsolved cases, where you examine the evidence, investigate the suspects, reconstruct the timeline, and discover how the scarab disappeared.
# How to Play
1. Read the Case page to understand the crime.
2. Visit the Suspects page and investigate all six suspects.
3. Examine the Evidence page and study the clues.
4. Explore the Timeline page to reconstruct the events.
5. Go to the Deduction page.
6. Select the suspect you believe is responsible.
7. Write your reasoning and click Submit Deduction to check your answer.
